실제 공간정보 지도 연결 후 자동 표시

첨부 공간정보가 기본으로 포함되어 있습니다. 지도 연결 시 자동으로 불러옵니다.

건물 높이 누락분·외벽·지붕 표현은 추정입니다. 교량 상판 높이는 실측값이 아닙니다. 공간자료 기준연도와 2023년 운행 날짜는 다를 수 있습니다.

지도·로드뷰 연결

지도를 처음 열 때 엔진을 선택합니다. 실행 중 다른 엔진을 사용하려면 페이지를 새로고침하세요.

키는 이 탭에서 지도 공급원 요청에 사용하며 브라우저 저장소에 보관하지 않습니다.

Cesium 지형·건물 설정

Cesium 기본 지도는 실제 위성영상과 공개 DEM 지형입니다. ion 토큰을 연결하면 World Terrain과 OSM 건물을 사용할 수 있습니다.

카카오 실제 로드뷰

선택 차량 주변의 실제 촬영 지점을 찾습니다. V-World 지도는 그대로 유지됩니다.

카카오 개발자 콘솔의 해당 JavaScript 키에 이 페이지의 접속 도메인(예: http://localhost:8081)을 등록해 주세요. 키는 이 탭에서만 사용합니다. 카카오 공식 설정 안내

촬영 사진을 차례로 보여주는 모드입니다. 차량의 실제 GPS 영상이나 실시간 영상이 아니며 촬영 지점은 차량 좌표와 다를 수 있습니다. 3D 승하차·시설 모형은 V-World 화면에서 보입니다.

강내면 기본 경계

첨부된 QGIS 경계를 기본 레이어로 포함했습니다. 지도에서 테두리만 자동으로 표시됩니다.

기본 경계를 불러오고 있습니다.

검증된 도로망과 42개 실행자료가 이미 포함되어 있습니다. 추가 파일은 EPSG:4326 도로선 표시용이며 차량의 운행 경로와 이벤트는 원본 실행자료를 따릅니다.

# 건물 외관 표시 — v4

업로드된 실제 건물 외곽선과 높이·층수·용도 속성을 사용한다. 원본 건물 8,666개 레코드는 변경하지 않는다.

## 화면에 추가된 표현

- 일반 건물: 창문, 창틀, 출입문, 기단과 처마·층 구분 띠.
- 단독주택: 자료의 용도가 단독주택이고 외곽선이 적합한 경우 완만한 경사지붕.
- 공장·창고 등의 산업시설: 큰 출입문과 셔터, 상부 창, 금속색 지붕.
- 근린생활시설·공공시설: 유리 출입문과 작은 차양.
- 공동주택: 층별 창문 배열과 수평 구분.
- 용도 미상 또는 속성 오류 건물: 중립적인 외벽과 출입구. 특정 상호나 용도를 만들어 넣지 않는다.

건물별 이름·용도 텍스트는 표시하지 않는다. 별도 사진이나 측량된 외관 자료가 없으므로 창문·출입구 위치, 외벽 색, 차양과 지붕 구성은 시각적 표현이다. 실제 건물 사진과 동일한 외관이라는 뜻은 아니다.

## 원자료와의 관계

경사지붕은 구멍이 없고 볼록한 단독주택·산업시설 외곽선에만 생성한다. 지붕 면은 원래 외곽선 안에 위치하고, 최고점은 기존 높이를 유지한다. 해당 조건에 맞는 1,057개 외곽선에 적용된다. 복잡한 외곽선·중정·미확인 용도는 기존 평지붕을 유지한다. 층수 자료가 없을 때 창문 층 배열에 사용하는 약 3.15m 간격은 표시용이다.

강내우체국·물류하차지·정류장의 전용 모형과 직접 겹치는 일반 건물 면만 표시에서 제외한다. 원본 GIS 데이터는 삭제하지 않는다. 시설 레이어를 끄면 해당 시설에 대한 제외도 해제한다. 중정 안에 시설이 있는 경우에는 중정을 건물 면으로 취급하지 않는다.

## 표시 성능

650m 이내 건물에는 창문·출입구를 표시하며, 260m 이내에는 창틀·손잡이·차양 등 세부 표현을 추가한다. 카메라 고도가 2,800m 이상이면 세부 외벽을 해제하고 건물의 외곽선과 지붕 형태를 유지한다. 세부 메시를 재료별로 묶고, 타일당 최대 140개 가까운 건물을 대상으로 구성한다. 원래 도로·교량·지형·운행 시각·배차 결과는 바꾸지 않는다.

## 검증

- 8,666개 건물의 외관 메시 좌표·인덱스·법선 유효성 검사.
- 경사지붕 최고 높이가 원자료의 높이를 넘지 않는지 검사.
- 중정과 오목한 외곽선을 임의의 지붕으로 덮지 않는지 검사.
- 시계방향·반시계방향 외곽선 모두 바깥쪽 창문 면이 생성되는지 검사.
- 실제 번들 Cesium의 GeometryPipeline으로 세부 메시의 지구중심 좌표 인코딩 검사.
- 거리·고도에 따른 세부 메시 제거/복원 및 시설 우선순위 생명주기 검사.

이 검증은 코드와 지오메트리 검증이며, 실제 V-World 인증키가 있는 사용자 브라우저에서의 GPU 표시 확인을 대신하지 않는다.

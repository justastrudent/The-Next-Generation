# v6 건물 외관 개선

사용자가 첨부한 v4 ZIP을 기준으로 제작. 실제 개별 건물 사진은 포함하지 않음. 외벽 창문 반복 격자 제거, 아파트 주요 면에 소수의 넓은 발코니 구획, 주택/상업/산업 용도별 간단한 출입구와 표면, 가까운 건물에 원본 제작 벽체 및 지붕 재질 텍스처. 용도 미확인 건물에 임의 창문을 만들지 않음. 기존 GIS 건물 표시를 끄면 V-World 제공 건물을 복원하는 기존 동작 유지. DRT 위치 표식 크기 축소.

원본 GIS·운행·배차 자료, 시설 모델과 지도 라이브러리 변경 없음. 실제 V-World 건물 제공 범위와 인증키 연동, GPU 렌더링은 미검증. Chromium 페이지 탐색이 관리자 정책에 의해 차단됨. 자동 테스트 44개 통과, 1개는 외부 원본 CSV 부재로 실행 미완료.

`py serve.py --port 8080`으로 실행. 화면의 v6 표시 확인.

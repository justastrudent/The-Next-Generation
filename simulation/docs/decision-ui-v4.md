# 의사결정 화면 V4

## 화면 변경

- 현재 차량 상태와 경로 지도를 가장 먼저 배치했습니다.
- 선택한 DRT의 현재 위치는 밝은 표식과 차량 번호로 표시하고 화살표로 진행 방향을 표시합니다.
- 본문은 14px, 주요 제목은 17~21px, 영향 수치는 28px로 구성했습니다. 글과 배경의 대비를 높였습니다.
- 신규 호출은 최근 1건과 전체 접수·대기 건수를 표시합니다. 다음 작업은 3건까지 표시합니다.
- 변경 전·후 목적지, 약속 대기, 제약을 통과한 삽입 후보 수, 기존 승객 추가 대기, 다음 배송 시각의 변화를 표시합니다.
- 방법론과 출처 설명은 접을 수 있는 「알고리즘 · 수치 출처」에 모았습니다.

## 현재 위치의 기준

`context.states`는 기존 3D 차량과 동일한 `replay-core.stateAt()`의 결과입니다. SVG 지도는 이 좌표와 진행 방향을 직접 사용합니다. 해당 상태가 전달되지 않는 호출 환경에서만 같은 `stateAt()`을 이용합니다.

차량이 이동할 때는 경로 SVG 전체를 다시 만들지 않고 차량 표식만 갱신합니다. 현재 위치가 지도 범위를 벗어나면 계획 경로와 현재 위치가 함께 들어오도록 표시 범위를 조정합니다. 원본 좌표를 옮기거나 계획 경로에 붙이지 않습니다.

날짜·운영 방식·시나리오 전환 중(`runLoading`)에는 이전 차량·경로·호출을 숨깁니다. 새 운행 기록이 준비되고 의사결정 파일만 로딩 중인 경우에는 새 차량의 현재 위치를 표시합니다. 정차와 가상 주차 탐색은 기존 재생 위치를 그대로 사용하며, 경로 미확인 상태는 방향 화살표 없는 「기준 위치」로 구별합니다.

현재 위치는 서비스 노드 또는 도로망 보간 결과입니다. GPS 관측 기록으로 표시하지 않습니다. 계획 전후 ETA 차이는 물류만의 인과효과로 해석하지 않습니다.

## 검증

- 기존 의사결정 화면 데이터 검사: 114개 통과
- V4 위치·방향·변환 중 오래된 상태 차단·되감기 검사: 64개 통과
- 원본 이벤트, 도로 좌표, 배차 엔진과 결과 파일은 변경하지 않았습니다.

`previews/decision-map-v4.svg`는 2023-11-06 통합운영 S1, 08:32:31, DRT 1의 실제 제공 데이터로 만든 지도 출력입니다. 전체 브라우저 화면이나 지도 SDK의 실행 캡처는 아닙니다.

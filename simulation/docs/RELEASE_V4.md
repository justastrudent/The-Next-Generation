### 시설이 가려진 구조적 원인

강내우체국 전용 모델과 일반 건물 ID `196849`가 직접 겹쳤다. 표시 높이는 일반 건물 7.3m, 전용 모형 약 3.83m다. 전용 시설 120개의 실제 모델 치수와 GIS 도형을 교차 검사하여 8,666개 일반 건물 중 37개만 충돌함을 확인했다. 근처 건물을 반경으로 일괄 제거하지 않는다. 여러 부분으로 된 도형과 안마당의 빈 공간도 구분한다.

정류장·물류하차지 레이어를 끄면 해당 시설의 표시 우선순위도 해제한다. 일시정지 중에도 즉시 적용된다. 시설의 기존 배치 좌표·크기·승객 대기 위치는 유지한다. 자세한 근거는 [원본·시설 검증](source-verification-v4.md)을 참고한다.

### 차량 표식의 의미

위치는 계획의 시작점이나 목적지가 아닌 현재 재생 시각의 차량 상태다. 이동 중에는 도로망·통행시간 보간, 정차 중에는 서비스 노드 위치를 사용한다. 가상 주차 탐색은 기존 대기 위치에 머문다. 경로를 확인하지 못하는 경우에는 기준 위치로 표시하고 방향 화살표를 보이지 않는다.

새 날짜·운영 방식·시나리오를 로딩하는 중에는 이전 운행의 표식과 경로를 숨긴다. 새로운 운행이 준비된 뒤 의사결정 JSON만 읽는 중이라면 해당 운행의 현재 위치부터 표시한다. 미래 호출이나 아직 기록되지 않은 실제 대기 결과는 미리 나타내지 않는다.

## 실행과 확인

1. ZIP 전체를 새 폴더에 압축 해제한다.
2. 실행 중인 이전 서버가 있다면 그 창에서 `Ctrl+C`로 종료한다.
3. 새 폴더의 `index.html`, `serve.py`, `data`, `assets`가 보이는 위치에서 터미널을 연다.
4. `py serve.py`로 실행한다. 기존 8080 주소를 유지하려면 `py serve.py --port 8080`을 사용한다.
5. 브라우저에서 새 로고와 `건물·의사결정 v4` 표시를 확인한다. 이전 화면이 남으면 `Ctrl+F5`로 다시 읽는다.
6. 기존 방식으로 V-World를 연결하고 `DRT 경로 및 의사결정`을 선택한다.

확인하기 좋은 실제 기록: **2023-11-06 / 여객+물류 / S1 / 08:32:31 / DRT 2**. 현재 차량 표식, 기존 점선 경로, 변경 후 민트색 경로, 다음 작업을 함께 볼 수 있다. 다른 차량으로 바꾸거나 5분 되감아 위치가 바뀌는지도 확인할 수 있다.

건물의 창문·출입구는 차량 추적·눈높이처럼 가까운 시점에서 잘 보인다. 먼 조감도에서는 외곽선과 지붕을 유지하고 상세 외벽을 줄인다. 자세한 범위는 [건물 외관 설명](building-appearance-v4.md)에 있다.

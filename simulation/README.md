# MetroRookies · 발표 화면 v7

첨부된 **MetroRookies_Visual_Decision_v6.zip**을 기준으로 승인된 발표·모바일 개선만 적용한 전체 실행본입니다.

- 실행: 이 폴더에서 `py serve.py --port 8080` → `http://localhost:8080/`.
- 기존 기본 실행 `py serve.py`는 그대로 `http://localhost:8081/`을 사용합니다.
- v7 확인: 화면의 **발표 화면 v7** 표시 또는 **설정 → 발표 화면** 옵션을 확인합니다.
- [v7 변경 내용, 실행 안내, 데이터와 검증 범위](docs/RELEASE_V7.md)
- [기존 공간정보·추정 외관 안내](docs/environment-data.md)
- [원본 배차 알고리즘과 ETA 근거](docs/dispatch-methodology.md)

핵심 변경: 휴대폰·태블릿 대응, 경로와 호출·대기·배송 정보 동시 표시, 연속 배속 조절, 시간 탐색 최적화, 호출 알림, 승하차 말풍선, 강내우체국의 정차 우편 차량, 지도 레이어 설정 정리.

기존 QR 주소에 적용하려면 해당 주소를 서비스하는 호스팅 폴더의 파일을 이 전체 패키지로 갱신해야 합니다. ZIP 다운로드만으로 기존 웹사이트가 변경되지는 않습니다. 이번 작업에는 배포가 포함되지 않습니다.

실제 V-World 인증 세션과 휴대폰 터치 화면은 이 작업 환경의 브라우저 접근 제한으로 직접 검증하지 못했습니다. 코드·실행자료 검증 결과와 외부 지도/단말의 화면 확인은 구분합니다.

## 기존 기능과 연구자료 안내

첨부된 `gangnae_vworld_qgis_3d` HTML의 경로·시간·이벤트 처리를 실제 연구자료 재생 구조로 교체한 로컬 실행 패키지입니다. 기존 HTML은 이 패키지의 `gangnae_vworld_qgis_3d_fixed.html`로 교체하고, 함께 제공하는 JavaScript·data·assets·vendor 폴더를 유지합니다.

## 1. 바로 실행하기

1. ZIP을 압축 해제합니다.
2. `gangnae_vworld_qgis_3d_fixed.html`, `index.html`, `data/`, `assets/`가 보이는 폴더에서 터미널을 엽니다.
3. 다음 명령을 실행합니다.

```bash
python -m http.server 8081 --bind 127.0.0.1
```

Windows에서 `python` 명령이 없으면 설치 환경에 따라 `py -m http.server 8081 --bind 127.0.0.1`을 사용할 수 있습니다.

4. 브라우저에서 다음 주소를 엽니다.

```text
http://localhost:8081/gangnae_vworld_qgis_3d_fixed.html
```

`http://localhost:8081/`도 같은 앱을 엽니다. HTML을 더블클릭하는 `file://` 실행은 데이터 파일과 모듈을 읽는 브라우저 제한 때문에 지원하지 않습니다.

5. 지도 엔진을 선택합니다.

- **V-World:** 「V-World 인증키 입력」을 누르고 해당 접속 주소에서 사용할 수 있는 인증키를 입력합니다. 키는 현재 탭의 지도 요청에만 사용하며 `localStorage`에 저장하지 않습니다.
- **Cesium:** 「Cesium으로 열기」를 누르면 별도 키 없이 기본 위성영상·공개 DEM 지형을 사용합니다. 선택적으로 Cesium ion 토큰을 넣어 World Terrain과 OSM 건물을 연결할 수 있습니다.

지도와 실행자료가 준비된 뒤 재생 버튼이 활성화됩니다. 지도 엔진을 바꾸려면 페이지를 새로고침합니다. 인터넷은 지도·지형 공급원 연결에 필요하며, 연구 결과·도로망·기본 3D 모델·Cesium 라이브러리는 패키지에 포함되어 있습니다.

## 이번 수정: 로드뷰 · 기본 경계 · 서비스 장면

기존 지도와 연구자료에 요청한 표시 기능만 추가한 전체 패키지입니다. 별도 설치 프로그램이나 BAT 파일을 실행할 필요가 없습니다.

### 실제 카카오 로드뷰 열기

1. 기존처럼 V-World를 연결하고, 지도 위 **실제 로드뷰**를 누릅니다. 로드뷰만 먼저 연결하는 것도 가능합니다.
2. **연결 설정**에서 카카오 **JavaScript 키**를 입력한 뒤 **로드뷰 연결**을 누릅니다. REST API 키를 쓰는 칸이 아닙니다.
3. 카카오 개발자 콘솔에서 해당 JavaScript 키에 **JavaScript SDK 도메인**을 등록해야 합니다. 현재 공식 가이드 경로는 `[앱] → [앱 설정] → [앱] → [플랫폼 키]`입니다.
4. 로컬 접속이라면 `http://localhost:8081`을 등록합니다. `http://127.0.0.1:8081`이나 팀 공유 웹주소로 접속할 경우 그 주소도 별도로 등록해야 합니다. 도메인에 프로젝트 하위 경로를 붙이지 않습니다.
5. 왼쪽에서 차량을 선택하고 재생하거나 타임라인을 이동하면 해당 차량 주변의 촬영 지점을 찾습니다. **차량 방향 따라보기**를 켜면 진행 방향을 바라봅니다. 화면을 직접 드래그하면 자동 방향 추적이 해제되며 체크박스로 다시 켤 수 있습니다.
6. **조감도 / 차량 추적 / 눈높이 / 차량 내부**를 누르면 기존 3D 화면으로 돌아옵니다. 3D 승하차·적재·시설 모형은 이 화면에서 보입니다.

`getNearestPanoId()`로 50m 이내를 먼저 찾고 없으면 100m 이내를 찾습니다. 이동 중에는 약 1.2초 간격 및 8m 이동 기준으로 조회를 제한합니다. 촬영 지점이 없으면 이전 사진을 현재 위치의 사진처럼 남기지 않고 안내합니다. **주변 다시 찾기**로 재시도할 수 있습니다. 차량과 사진 촬영 지점의 차이는 화면에 거리로 표시합니다.

로드뷰는 실제로 촬영된 파노라마 사진을 순서대로 보여줍니다. 실시간 주행 영상이나 2023년 운행 당시 영상이 아니며, 모든 도로의 촬영 사진이 제공되는 것은 아닙니다. 실행 결과의 차량 위치·시각은 기존 자료를 사용하고 로드뷰가 차량의 연구 위치를 바꾸지 않습니다. 키는 현재 탭의 공식 SDK 요청에만 사용하며 소스 파일이나 브라우저 저장소에 저장하지 않습니다. 새로고침하면 다시 입력합니다.

공식 설정: https://apis.map.kakao.com/web/guide/  
공식 로드뷰 API: https://apis.map.kakao.com/web/documentation/#Roadview

### 강내면 경계 기본 표시

첨부 ZIP의 프로젝트 맨 위에 있던 실제 QGIS `gangnae_boundary.geojson`을 **`data/gangnae_boundary.geojson`**에도 그대로 넣었습니다. 앱을 열면 자동으로 읽고 **금색 테두리만** 표시합니다. 내부 면은 채우지 않으며 파일 선택을 요구하지 않습니다.

지도 위 **강내면 경계** 체크박스로 숨기거나 다시 표시할 수 있고, 지도 설정의 **경계 전체 보기**로 영역을 볼 수 있습니다. 날짜·시나리오·운영 방식이 바뀌어도 경계는 유지됩니다. 팀원에게 ZIP 전체를 보내면 같은 경계가 기본으로 나타납니다. 경계 좌표를 다시 그리거나 도로망을 잘라내지 않았습니다.

### V-World 조감도와 사람·시설

- V-World의 원래 지도·지형 공급원을 유지합니다. 조감도 각도를 조금 더 위에서 내려다보도록 조정하고, 지원되는 엔진에서는 지형 세부 묘사를 높입니다.
- 공개 `scene.verticalExaggeration` 기능이 있는 엔진에서는 높이 배율을 **0.9**로 완만하게 표시합니다. 이 기능이 없는 구형 V-World 엔진에서는 원래 고도를 유지하고 각도·세부 묘사 개선만 적용합니다. 영상에 찍힌 건물 왜곡을 제거하거나 도로를 실측 평면으로 만드는 기능은 아닙니다.
- 외부 승객의 얼굴·머리·옷·손·신발과 신체 비례를 개선했습니다. 걷기 관절은 기존 승하차 애니메이션에 연결합니다.
- 강내우체국에 우체국 모형, 물류하차지 옆에 마을회관 모형, 정류장 옆에 쉘터 또는 팻말을 배치합니다. 정류장 대기 인물이 해당 장소에서 차량 문으로 이동합니다.
- 시설 외형·면적·방향·도로 옆 배치와 쉘터/팻말 선택은 **시각화용 가정**입니다. 실제 시설 현장조사나 건물 모델을 뜻하지 않습니다. 우체국은 제공된 원래 POI 좌표가 있으면 사용하고, 원본 도로 위 서비스 노드는 유지합니다.
- **물류거점** 표기를 **물류하차지**로 바꾸고, 작은 주황색 점을 같은 정도 크기의 네모로 바꿨습니다.
- 상자는 기록된 수량에 따라 하나씩 짧게 이동합니다. 최대 8개의 동작은 문 여닫기를 포함해 약 36초의 시뮬레이션 시간 안에 연출되며 짧은 서비스 구간에서는 그 안에 맞춥니다. 실제 물류량·승객 수는 기존 로그의 서비스 완료 시각에 갱신됩니다. 시각적 동작이 먼저 끝나도 로그가 완료될 때까지 차량은 기존 상태를 유지합니다.

청주콜 차량 외형, 정차 차량 간격, 42개 실행의 연구자료, 차량 경로, 운행조건과 비용 계산은 유지했습니다. `docs/model-previews/`는 내보낸 GLB를 다시 불러와 확인한 모형 미리보기이며 실제 지도 화면 캡처가 아닙니다.

## 3. 기존 코드에서 바꾼 핵심

### 3.1 도로망 표시와 차량 경로를 분리

기존 `mergedCoords`에서 GeoJSON 전체 링크를 파일 순서대로 합치고 시작점을 강제로 붙이던 처리를 제거했습니다.

각 차량 이벤트의 `pathId`를 이용해 다음 경로를 선택합니다.

```js
const route = run.routes[event.pathId];
```

이 경로는 원본 시뮬레이션 전처리와 방향성·통행시간을 반영한 네트워크에서 복원했습니다. 업로드 GeoJSON은 선분별로 추가 표시할 뿐, 차량의 운행 경로나 이벤트 시각을 바꾸지 않습니다.

### 3.2 80초 반복을 하루 전체 시간축으로 교체

`simTime % 80`과 고정된 4단계 시간표를 제거했습니다. 재생 시각은 연구 로그와 같은 **06:00 이후 경과 분**입니다.

```js
time = Math.min(990, time + deltaSeconds * playbackSpeed / 60);
```

| `time_min` | 시각 | 의미 |
|---|---|---|
| 30 | 06:30 | 운행 시작 |
| 150 | 08:30 | 물류 수요 발생 |
| 960 | 22:00 | 서비스 종료 |
| 990 | 22:30 | 복귀 기한 |

초기 화면은 06:30에 일시정지되어 있습니다. 재생, 일시정지, ±5분, 슬라이더, 이전·다음 이벤트, 특정 이벤트 선택을 지원합니다.

### 3.3 차량 3대 상태를 시각의 함수로 계산

프레임마다 인원·상자 수를 더하거나 빼며 누적하지 않습니다.

```js
const prepared = prepareRun(run, network);
const states = stateAt(prepared, time, selectedVehicle);
scene.update(states, time);
```

동일한 `time`이면 동일한 위치와 수량을 계산하므로 뒤로 되감아도 일관된 상태가 됩니다. 잘못된 시간 가중치가 있는 경로는 정점별 동일 시간으로 대신 움직이지 않고 미확인 상태로 처리합니다.

### 3.4 이동·서비스·완료를 구분

| 시간 구간 | 차량 위치·상태 |
|---|---|
| `departure ≤ t < time` | 복원된 도로 경로를 링크별 통행시간에 따라 보간 |
| `time ≤ t < completed` | 로그의 도착 노드에 정차, 해당 서비스 애니메이션 |
| `completed ≤ t` | 로그의 서비스 완료 후 승객·물류 수량 적용 |

이동 위치는 `route.fractions`의 누적 시간 비율로 계산합니다. 이동거리는 별도의 `route.distanceFractions`로 계산하여, 속도가 다른 링크를 통과할 때 시간 비율과 거리 비율을 혼동하지 않습니다.

호출·승하차·배송 시각을 새로 생성하지 않습니다. 사람의 걷기와 문·상자 동작은 기록된 서비스 구간 안에서 연출하는 시각화입니다.

### 3.5 표시 조건·지도 준비 상태 수정

- `Entity.show`에는 실제 Boolean 값을 전달합니다.
- 모델 내부의 문·트렁크·객실 점유는 `ModelGraphics.nodeTransformations`로 갱신합니다.
- V-World SDK와 viewer 준비를 기다린 뒤 3D 객체를 생성합니다.
- 지도 준비 전에는 시간 재생을 차단합니다.
- 인증 실패·응답 지연·지원하지 않는 API 상태를 성공으로 표시하지 않습니다.
- 지형 높이를 못 읽었다고 고정 45m를 부여하지 않습니다. 지형 연결 상태를 표시하고, 실제 지형 사용 중 고도 미확인 위치의 근접 카메라는 고도를 기다립니다.

V-World SDK는 기존 페이지에 직접 `document.write()`하지 않고 별도 같은 출처의 `vworld-host.html` 프레임에서 로드합니다. 실제 호스트 주소를 유지하면서 V-World가 제공하는 Cesium과 동봉한 Cesium이 같은 전역 객체를 덮어쓰는 일을 피합니다. 인증키는 부모가 프레임 객체에 잠시 전달하며 앱의 URL에 넣지 않습니다.

## 4. 재생 데이터 예시

아래는 스키마 설명입니다. 숫자를 실제 연구 기록으로 추가해서는 안 됩니다.

```text
run.events[]
  vehicle                 차량 1·2·3
  kind                    PU / DO / LOAD / RESTOCK / DELIVER / RETURN / PARK_SEARCH 등
  departure               이동 출발 시각, 06:00 이후 분
  time                    서비스 도착 시각
  completed               서비스 완료 시각
  from, to                실제 네트워크의 출발·도착 노드 ID
  pathId                  run.routes의 키
  passengers, cargo       서비스 완료 후 수량
  distanceKm, travelMin   원본 로그의 거리·이동시간

run.routes[pathId]
  coordinates             순서와 방향이 확인된 도로 경로 좌표
  fractions               누적 이동시간 비율
  distanceFractions       누적 이동거리 비율
  graphNodes, parentLinks 경로 복원 근거
```

## 5. 연구 해석상 유지한 조건

- Depot은 **강내우체국**입니다. 노드의 원래 위치와 도로에 투영한 서비스 위치를 함께 제공합니다.
- 날짜는 2023-11-06~2023-11-12, 운영 방식은 여객 전용/통합운영, 목적함수는 S0/S1/S2입니다.
- 차량당 승객 정원 11명, 물류 적재 한도 8개입니다.
- `PARK_SEARCH`는 마지막 서비스 위치에서 정지시키고 가상 시간·거리만 반영합니다. 실제 주차장을 방문하는 경로를 만들지 않습니다.
- 15분 초과 대기 결과를 그대로 표시합니다.
- S2 목적함수 비용계수는 참고용 상태입니다. 별도의 연간 운영원가 추정표와 구분합니다.
- 일별 전력비 추정은 선택 실행의 총거리 × 0.256kWh/km × 295원/kWh입니다. 연간 원가표는 차량 3대 전체의 통합운영 추정치입니다.
- 재현 위치는 도로망 기반 추정·보간입니다. 실제 GPS 관측, 유일한 역사적 경로, 전역 최적해를 의미하지 않습니다.

## 6. 원본 자료로 데이터 다시 만들기

이미 포함된 `data/`를 사용할 때는 이 단계가 필요 없습니다. 원본 결과를 바꾸거나 다시 변환할 때 사용합니다.

```bash
python -m pip install -r scripts/requirements.txt
python scripts/convert.py --repository /absolute/path/to/MetroRookies --output data
```

주요 원본은 김민상 최종 시뮬레이션 코드 ZIP, 날짜별 최종 결과 ZIP, 강내면 우회경로 확장 검증본 GeoPackage 및 속도30 링크 CSV입니다. 저장소 경로와 파일 해시는 `data/provenance.json`을 확인하세요. `scripts/vendor/gangnae/PROVENANCE.md`에는 재사용한 원본 전처리 코드의 출처가 있습니다.

## 7. 3D 모델을 바꿀 때

기본 GLB에는 `DOOR`, `HATCH`, `PAX_0`~`PAX_10`, `CARGO_0`~`CARGO_7` 노드가 있습니다. 임의 차량 GLB로 파일만 교체하면 이 노드가 없거나 축·크기·바닥 원점이 달라 문·객실 애니메이션이 맞지 않을 수 있습니다. 모델 노드와 좌표 보정을 함께 변경하세요.

현재 수정본은 동작 노드가 있는 기본 모델을 제공합니다. 외부 파일을 선택하자마자 로드 성공으로 처리하던 기존 업로드 동작은 포함하지 않습니다.

## 8. 검증 범위

원본 42개 실행의 이벤트·거리·통행시간 대조와 재생 엔진 검사를 제공합니다. 초기 지도 대기, GeoJSON 선분 분리, 날짜·시나리오 변경 경합, 서비스 완료 수량, 되감기, 종료 시각 등은 브라우저를 대신한 DOM/지도 테스트 객체와 순수 계산 검사로 확인합니다.

**실제 V-World 인증키를 넣은 WebGL 브라우저 실행은 이 제작 환경에서 확인하지 못했습니다.** 관리형 브라우저 미리보기 연결도 사용할 수 없어, 화면 렌더링과 공급원별 실기동 확인은 로컬 서버에서 수행해야 합니다. 이 제한은 데이터·계산 검증과 구분합니다.

경계 파일은 사용자 ZIP의 QGIS 형상과 동일한지 확인했습니다. Polygon 내부 구멍·MultiPolygon·선형 처리 등은 합성 도형으로 검사합니다. 로드뷰는 SDK 모의 객체로 최근 차량 좌표 사용, 촬영 지점 없음, 되감기, 날짜·차량 변경, 늦은 응답과 타임아웃을 확인합니다. 시설 배치·상자 동작은 원본 데이터를 바꾸지 않는지 검사하고 GLB는 다시 불러와 렌더 확인합니다.

**실제 카카오 JavaScript 키와 등록 도메인에서의 영상 출력도 이 환경에서는 확인하지 못했습니다.** 모의 테스트는 인증·촬영 범위·타일 제공 여부를 보장하지 않습니다. 기존 `replay-core`의 원본 CSV 전수 대조 결과는 이전 데이터 제작 단계의 결과이며, 이번에는 최신 ZIP의 연구 데이터와 핵심 계산 코드가 바뀌지 않았는지 해시로 확인합니다.

검사 프로그램은 `tests/`, 실행 결과 파일은 `docs/`에 있습니다. V-World 접속 키·도메인·네트워크 응답에 따른 상태는 화면에서 확인할 수 있습니다.
